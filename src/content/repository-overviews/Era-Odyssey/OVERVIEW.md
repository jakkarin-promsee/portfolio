## My first website gave our educational game a world people could explore before playing.

Era Odyssey was the first game I made with friends in grade 11. We taught ourselves the tools and wrote the game by hand, learning from textbooks and what we could find at the time. The Unity game held the combat and learning systems, but a download alone could not introduce its story, creatures, periods, and team. I built a companion website as a public face for that larger project and as my first attempt to give a game its own place on the web.

## Turning game material into a browsable guide

The site connects seven themed areas: a story opening, creature pages, geological information, animations, a gallery, team context, and download links. Visitors meet Demain H. Cover and the time-travel premise before choosing to play. Static HTML, CSS, JavaScript, JSON, and image assets carry that experience; this repository does not run the Unity game in the browser.

The site grew from the need to explain as well as present. Game art and period information became pages that someone could browse independently, while the Play page pointed toward the original game files. The README includes much more about combat, crafting, and quizzes, but those are features of the related [Unity game](/repositories/Unity-EraOdesey), not JavaScript features of this website.

This repository preserves the presentation side of a self-taught team project and a personal first website milestone. The historical download links and current availability of the original game files need separate checking; the checked-in site itself is a static companion, not a maintained online game service.
