# Era Odyssey (Unity Game)

Categories: [educational game, Unity, game systems]

Summary: Archived Unity and C# source for a high-school team's 2D educational idle combat game about Earth's geological history. Players progress through stages in the Cambrian, Ordovician, and Silurian periods, fight creatures and bosses, collect materials, craft and equip gear, and develop elemental skills. A Book of Era and timed questions bring the historical learning material into the game loop; this repository preserves scripts and selected assets, while the complete original project was stored separately.

Highlights:
- Period-specific stages with enemy rounds, bosses, experience, and material drops.
- Two-material crafting, weapon and armor equipment, and Fire/Water/Frost/Earth skill systems.
- Book of Era reading and a timed true/false quiz with Thai and English question assets.
- JSON save data for progression, inventory, equipment, and skills.

Tech stack: [Unity, C#, MonoBehaviour, ScriptableObjects, JSON]
