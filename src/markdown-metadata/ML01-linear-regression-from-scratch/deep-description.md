# ML01 — Linear Regression and Backpropagation From Scratch

## The learning problem

This is a from-scratch study of how a model learns, not a benchmark or reusable deep-learning framework. The starting point is a single affine regression layer, `XW + b`. The work then adds hidden layers and ReLU, first with the forward and backward calculations written out in the notebook and finally through reusable layer classes. The synthetic targets are curved functions of a scalar input, so the project can expose the representational limit of a single affine mapping and compare it with piecewise-linear networks.

## The four experiments

1. **Linear baseline.** Two features, including a square term, feed a single affine layer. This is linear in its supplied features even though the original scalar relationship is curved.
2. **One hidden layer.** The notebook computes dense preactivations, applies ReLU, and ends in a linear regression output. This makes the mapping nonlinear in the input.
3. **Three hidden layers.** The same chain rule is expanded across multiple matrices; the notebook uses an identity activation on the third hidden layer.
4. **Composable version.** `custom_library/models.py` supplies dense and activation layers, a model class, and training history so layer construction is no longer repeated by hand.

All four use synthetic data generated by the notebook. Random initialization, data noise, and the train/evaluation split mean a single numeric score should not be treated as a fixed result.

## The mathematics turned into code

The derivation uses row-oriented batches: `Z[l] = A[l-1] W[l] + b[l]`, then `A[l] = f(Z[l])`. The output is linear and training minimizes batch mean squared error. For `m` examples and one output, the output error is `2/m * (Y_hat - Y)`. Weight gradients are the previous activations transposed times that error; bias gradients sum it over examples. Backpropagation multiplies the error by the next weight matrix transposed and by the previous layer's activation derivative. ReLU's derivative at zero is chosen as zero. Parameter updates happen after backward gradients are calculated, preserving the weights used in the forward pass.

The README also explains a conceptual trap: stacking affine layers without an intervening activation still collapses to one affine transform. ReLU creates different active-unit patterns and therefore a piecewise-affine function. The project uses this argument to distinguish the initial linear regression from the later feedforward neural networks.

## Training and evaluation

The composable model trains with mini-batch gradient descent, using the actual size of each batch, including the last partial batch. Training optimizes MSE; the notebook presents MAE and predicted-versus-true plots for interpretation. The evaluation split is used for monitoring rather than gradient updates. The custom library contains data splitting, activations, regression metrics, layer implementations, and history utilities. Its scope is deliberately small: dense layers, optional ReLU, scalar regression targets, and educational inspection of gradients.
