# Toram-Bot01

Categories: [Python automation, game tooling, experimentation]

Summary: An early series of Python scripts that automate Toram Online farming through keyboard presses, mouse clicks, window focus, timers, and screen-pixel checks. The successive bow-bot versions move from fixed action sequences toward randomized timing, buff tracking, mana-aware skill use, and a scripted item-selling route. The latest script still requires the game window to stay active and relies on fixed UI coordinates and delays, making it a personal automation experiment rather than a robust unattended system.

Highlights:
- Records an explicit progression across magic and bow automation scripts.
- Uses wall-clock time to renew buffs and schedule inventory selling.
- Checks a screen pixel near the mana display before using a skill.
- Includes failed window-switching and hiding experiments, preserving what was tried.

Tech stack: [Python, PyAutoGUI, PyGetWindow, desktop input automation]
