# Era Odyssey Companion Website

Categories: [web development, game showcase, educational media]

Summary: A static companion site that presents a high-school team's educational game about Earth's geological eras. It gives visitors a narrative entry point, creature and period information, galleries and animation, team context, and links to game downloads. The site is a separate presentation and documentation layer around the Unity game, whose combat, crafting, and quiz systems live in another repository.

Highlights:
- Seven themed pages: Home, Monster, Information, Play, Animation, Gallery, and About.
- Story world introduces Demain H. Cover, Saxabra island, and the Si-2505 time-travel device.
- Creature, geological-period, visual, and team material extend the game's educational setting.
- Play page preserves links to full game files and APK; README mirrors the Unity game guide.

Tech stack: [HTML, CSS, JavaScript, JSON, static assets]
