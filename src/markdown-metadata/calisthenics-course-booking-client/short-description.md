# Calisthenics Course Booking — Client

Categories: [Web Prototypes, Fitness, Booking UX]

Summary: A responsive React prototype that walks a trainee from discovering online or onsite calisthenics coaching through plan selection, a payment demonstration, session booking, and skill progression. It also includes distinct user, trainer, and admin login portals backed by the companion account API. The visual booking, transaction, balances, and skill data are intentionally client-side samples, so the project demonstrates a product experience and handoff design rather than a live reservation or payment system.

Highlights:
- Compare plans and prices, adjust package quantity, and record an optional health note in an order summary.
- Interactive payment agreement, mock PromptPay QR, slip picker, calendar slot selection, and booking recap.
- Public skill tree, movement details, evaluation views, and sample XP/status progression.
- Role-gated routes and persisted auth state integrated with the companion server's registration and session endpoints.

Tech stack: [React, TypeScript, Vite, Tailwind CSS, Zustand, Axios]
