# Hot Potato

Categories: [education technology, full stack web, AI]

Summary: A teacher-led learning platform that turns lessons into interactive reading, questions, and open-ended discussion with an AI study companion. Teachers retain control of the source material and how the tutor responds; students can explore public lessons and use AI without signing in, with account features adding saved answers and history. This repository is the system-level integration map for the separately deployable React client and Express server, including architecture, data-flow, operations, and cross-repository code navigation.

Highlights:
- Two connected journeys: teacher authoring/publishing and phone-first student learning/chat.
- AI-assisted import and drafting require teacher preview and acceptance before entering lessons.
- Four tutor modes use server-loaded lesson context and per-lesson teaching guidance.
- Cross-repository docs and a checked-in Graphify knowledge graph map UI, API, models, and operations.

Tech stack: [React, TypeScript, TipTap, Express, MongoDB, Google Gemini, Cloudinary, Graphify]
