# Repository detail notes

Background and private work-priority notes for the complete projects in [list.json](list.json). Tiers are planning notes only; never use them in the website UI.

## Complete projects

- https://github.com/jakkarin-promsee/causal-world-learning-and-transfer
  - Tier SSS: Independent research on how an agent can learn a hidden causal system through limited interventions and eventually transfer that knowledge to another agent. (On going, the repo have nothing yet except some math prove for now)

- https://github.com/jakkarin-promsee/manga-shelf-interface
  - Tier B: A local-first manga shelf I built to track titles, reading links, notes, and the last chapter I read. A small personal tool for a problem I kept running into.

- https://github.com/jakkarin-promsee/active-sensing-vis
  - Tier SSS: Independent computer vision research on whether a model can learn where to look next from a few high-resolution glimpses. Includes controlled experiments that test what the model actually learns.

- https://github.com/jakkarin-promsee/toktickit
  - Tier B: A role-based IT service desk built for a software engineering course. The main value was learning a disciplined team workflow through issues, tests, pull requests, and peer review.

- https://github.com/jakkarin-promsee/kmutt-y3-s1
  - Tier F: An Obsidian coursework vault and AI workflow for managing one semester's classes and assignments. I keep it public mainly because friends also use the setup.

- Hot-potato Group
  - https://github.com/jakkarin-promsee/hot-potato
  - https://github.com/jakkarin-promsee/hot-potato-client
  - https://github.com/jakkarin-promsee/hot-potato-server

  - Tier SSS: A full-stack learning platform designed for teachers and students with varying levels of technical experience. AI helps teachers turn existing material into interactive lessons and lets students ask open-ended questions grounded in those lessons.

- https://github.com/jakkarin-promsee/my-harness
  - Tier S: A terminal-based coding-agent harness built from scratch to understand the model/tool loop, permissions, context management, sessions, and provider integrations.

- https://github.com/jakkarin-promsee/bio-analog-cpu
  - Tier SSS: Independent research on continual learning under analog compute-in-memory constraints. Uses behavioral simulations and controlled experiments to study learning, forgetting, noise, and energy tradeoffs.

- https://github.com/jakkarin-promsee/chronoforge-fpga-engine
  - Tier SSS: A 2D game engine implemented directly in FPGA hardware, without a CPU or software runtime. It includes a Python authoring and compilation workflow for creating games that run as Verilog logic.

- https://github.com/jakkarin-promsee/ia-regression
  - Tier A: A Big Five personality quiz that turns a trained regression model into an interactive app. It can estimate missing answers and show a full result after a user answers only part of the questionnaire.

- https://github.com/jakkarin-promsee/calisthenic-outdoor-design
  - Tier ?: A collaborative design study for an outdoor calisthenics gym, combining Blender models with preliminary engineering and safety research. It is a design package, not a certified construction plan.
